## Theoretical Framework: Registers, Class, and Commodification
#### Registers as Class Indexes (Agha 2007)

Define “register” (linguistic styles linked to social contexts).

Cotter and Valentinsson’s “bivalent class indexing”: how coffee jargon signals both solidarity and distinction (2018, 52).

##### Postcolonial Linguistic Hierarchies (Cohn 1996; Mir 2010)

Historical context: English as language of colonial command, vernaculars as “subordinate.”

Contemporary gentrification: English terms (“latte,” “artisanal”) elevate chai’s class status.

#### Erasure and Exoticism (Gal and Irvine 2019)

Street chai’s linguistic simplicity (“doodh kam dena”/less milk) vs. cafés’ elaborate descriptions (“single-origin Assam with cinnamon notes”).
